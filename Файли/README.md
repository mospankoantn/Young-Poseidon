# Матеріали Young Poseidon

Тут зберігаються вихідні зображення, референси та документи. Робочі ресурси GameMaker залишаються в `sprites`, `objects`, `rooms` та інших папках проєкту.

## Організація

- **Документація**: дизайн, технічні матеріали й старі нотатки. Документи описують також плани; фактичний стан дивіться у кореневих `README.md`, `FIXES_APPLIED.txt` та `Що треба зробити.md`.
- **Графіка**: окремі папки для героя, ворогів, босів, зброї, ефектів, меню, оточення та інтерактивних об'єктів. Прев'ю лежать поряд із відповідними джерелами.
- **Графіка/Референси**: зображення з неописовими назвами, які не прив'язувалися до конкретної категорії навмання.
- **Портфоліо**: документ для презентації робіт.
- **Резервні копії**: збережена копія `pla.png~`.

Назви та вміст усіх 59 початкових файлів збережені. Шляхи у скриптах імпорту й документації оновлені. Нові матеріали додавайте до відповідної категорії; при перенесенні джерел, які використовує `tools`, оновлюйте й посилання в інструментах.
